# Agent Note: 客户端配置页沿用供应商页的横向切换动效

Status: implemented
Archived: 2026-10-16

## Problem

客户端配置页通过 hidden 瞬时切换 Codex 与 Claude，缺少供应商页已有的方向反馈。两端已常驻以保留草稿和展开状态，不能为了重播动画卸载编辑器。

## Decision

只在客户端配置页选择器点选时记录进入端和退场端。页头保持静止，配置正文以与供应商列表相同的 16px 位移、180ms token 和缓动同步滑入滑出。四个方向关键帧抽至共享样式文件，两个工作区直接消费；不抽取业务状态控制器。

退场层绝对定位、隐藏页头并设置 inert 与 aria-hidden，结束后恢复 hidden，组件不卸载。退场面板背景与边框透明，避免不透明面板遮挡进入端。只消费正文自身的动画结束事件；400ms 超时同时清除两端状态。隐藏页面或外部改变客户端时清除本页动效，不在首次进入或返回时重播。减少动态效果继续使用全局时长归零契约。

## Related decisions

检索活跃笔记中的客户端配置、ClientConfiguration、页签与横向切换。[供应商页动效](../../implemented/feature/2026-10-14-provider-client-tab-slide.md)部分重叠，保留其列表生命周期，仅共享关键帧；[客户端配置契约](../../implemented/feature/2026-10-12-current-client-configuration-contract.md)拥有参数与写入语义，本篇不改变它；[折叠原语](../../implemented/architecture/2026-10-14-unified-collapsible-primitive.md)明确排除页内切换，继续保留。其余命中属于配置、恢复与扩展，范围无关，没有需要归档的决定。

## Alternatives considered

- 只给新面板淡入：改动最少，但旧内容立即消失会产生空帧，无法沿用供应商页的连续横移反馈。
- 按客户端 key 重建编辑器：挂载即可重播动画，代码简单，但会丢失组件内的展开与编辑状态；保留现有双端常驻结构。
- 直接复制供应商关键帧：可完全隔离改动，但同一种视觉规则会有两个所有者；共享四个关键帧，定位和生命周期仍各归工作区。

## Consequences

- 收益：Codex 到 Claude 从右进入、向左退场，反向切换相反；页头不移动，两个工作区的视觉参数只有一个所有者。原有瞬时隐藏路径仅在无本页切换时使用。
- 状态边界：两端编辑器继续常驻，草稿与展开状态保留，退场内容无法交互或获得键盘焦点。首次进入、页面返回、外部选择客户端不播放本页切换动画。
- 代价：退场周期内两端正文同时可见；短时间内反向点选会从新的方向重新开始 CSS 动画。配置正文短暂使用 transform，弹层继续使用现有 Portal。
- 验证范围：笔记结构校验、差异审查、过时引用与冲突标记检查；按项目约束不运行编译、类型检查或自动化测试。桌面实际动画和键盘行为未运行验证。
