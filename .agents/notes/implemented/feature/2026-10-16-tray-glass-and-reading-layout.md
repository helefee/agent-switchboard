# Agent Note: 托盘原生玻璃与两层读数布局

Status: implemented

## Problem

托盘已有 Acrylic / Popover 原生材质，但 82% 不透明的网页染色与实体选中底遮挡桌面背景。供应商名称、窗口名、额度和切换槽挤在一行，币种套餐名会和数值单位重复，长名称与多个窗口争夺宽度。用户要求实现毛玻璃并优化文案与布局。

## Decision

保留 Tauri windowEffects 作为唯一桌面模糊所有者，托盘明确使用透明原生/WebView 背景。网页消费现有 chrome-bg 的深浅染色，悬停与选中使用透明叠色，不另造网页模糊或材质状态。

托盘尺寸由 tauri.conf.json 中 tray 的 width / maxHeight 唯一拥有；前端只报告完整内容高度，原生定位消费配置并限制在显示器工作区，不另存前端高度上限或定位函数内的固定宽度。前端布局握手由 useTrayPanelLayout 拥有，串行动作与 Escape 由 useTrayActions 拥有，布局和动作失败都回到既有结构化错误入口。布局观察面板、列表视口与完整列表内容；错误区域变化也触发尺寸报告。

tray-usage.ts 是托盘用量的唯一展示派生入口：一次转换缓存，产出已格式化的名称、数值、状态色、提示与警示。行、读数正文和隐藏测量节点消费同一个展示对象；隐藏节点仅测量已格式化文本，不重新解析或格式化数据。删除子组件的二次派生与 JSON 字符串依赖签名；尺寸观察包含各候选读数，字体变化不依赖聚合宽度是否改变。

供应商名和当前/切换状态占第一层；存在缓存读数或警示时，用量独占名称下方的第二层，无用量时保持紧凑。两个读数按第二层实际宽度及溢出提示的实际宽度测量，数字与单位整体保留，额外读数进入 +N 的原生提示。官方窗口使用当前语言的完整时间标签；共享格式化器删除已无运行时消费者的 compact 参数与缩写分支，同步移除旧缩写测试断言。仅当套餐名与单位相同才省略重复名称，其他脚本名称原样保留。不改查询、缓存、切换执行器或警示刷新边界。

## Related decisions

- [原生玻璃外框](../../implemented/architecture/2026-10-14-unified-native-glass-shell.md)拥有主窗口材质与应用级主题；本次只使托盘消费相同染色，不替代该决定。
- [托盘警示与刷新](../../implemented/feature/2026-10-14-tray-usage-alert-refresh.md)拥有警示派生、独立刷新按钮和串行操作。本次保留这些行为并更新其旧单行测量事实，两篇互链。
- 其余检索命中（图标、字体、用量可用性、出口策略）不拥有托盘布局，保留原决定。

## Alternatives considered

- 只降低底色不透明度，保留单行：改动小且能露出原生模糊，但名称与多个窗口仍争夺宽度，不能解决截图中的信息拥挤。
- 使用 CSS backdrop-filter：可精确指定网页模糊半径，但 WebView 无法用它采样窗口外的桌面背景；原生合成器才拥有这个边界，因此不增加第二套模糊。
- 每个读数做独立卡片并全部换行：能完整显示任意数量，但会使快速切换面板高度随数据急剧增长；保留最多两项和 +N，并允许列表受限滚动。
- 在前端继续裁剪高度、原生固定宽度：能少传参数，但配置和运行时拥有两套几何事实；改为原生统一读取配置，前端只报告内容高度。
- 删除测量并依靠 CSS 裁切：能减少布局代码，但无法保证整个数字与单位保留且用 +N 明确告知额外读数；保留仅负责几何的观察，不保留重复数据派生。

## Consequences

- 托盘透明配置与原生材质共存，选中和悬停不覆盖实体底色；两端共享两层布局，缺失读数不虚构零值，警示刷新仍是独立按钮。
- 名称和额度不再争夺同一行；重复单位名省略，官方时间标签本地化。删除托盘专用的 82% 染色、60% 行宽预算和无消费者的窗口缩写路径。
- 删除前端 TRAY_MAX_HEIGHT、定位函数内固定宽度、行与子组件的重复用量派生、JSON 字符串依赖签名和旧模块出口；不保留转发导出、兼容参数或第二套尺寸默认值。
- 两层用量增加部分行高，面板继续受 560px 高度上限约束。原生玻璃受操作系统、合成器与系统透明效果开关控制；浏览器不能证明桌面背景模糊。

## Verification

底层收敛完成源码调用点核对：运行时尺寸常量仅存在于托盘原生配置，唯一 resizeTray 调用报告完整内容高度；原生定位读取同一 width / maxHeight 并按工作区裁剪。展示派生仅在供应商行调用，正文与测量组件只消费展示对象。受影响源文件低于 500 行，函数低于 80 行；差异空白与旧出口检索通过。补充五个托盘展示用例，覆盖空态、单位去重、不可用时保留名称、失败保留缓存和双语言；原生定位用例同步当前函数参数，并补充可变宽度用例。上述测试代码本轮未执行。

只使用模拟数据、当前源 CSS 与静态 DOM 的浏览器预览：480px 深浅主题、320px 长名称和警示、英文文字均呈现两层布局；480px 下有读数的行高约 56.3px，无读数为 40px。读取 320px 模拟行几何没有行级横向溢出，显示数值的 clientWidth 与 scrollWidth 相同。该预览没有执行 React 组件与自动溢出测量，不是业务交互或原生模糊验收。

初次沙箱预览连接超时；仅绑定回环地址的沙箱外静态服务启动后，旧错误标签仍无法导航，重新创建同浏览器标签完成查看。首次从顶层读取 iframe 文档不受浏览器 DOM 接口支持，改为明确的 frameLocator 后获得上述几何证据。

两份 CSS 经 PostCSS 语法解析、托盘窗口 JSON 经解析核对透明背景与原生效果配置；差异空白、冲突标记与废弃调用检索完成。`verify-notes` 校验 50 篇活跃笔记与 6 篇归档通过。尝试静态解析 TSX 的辅助检查因当前 TypeScript 包未导出 ScriptTarget / createSourceFile API 而未完成，不计为语法通过；没有安装其他解析依赖或改跑类型检查。

按项目要求不运行编译、类型检查或自动化测试。系统模糊与真实窗口交互尚待原生验收。
