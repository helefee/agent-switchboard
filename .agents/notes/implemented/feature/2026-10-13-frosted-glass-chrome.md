# Agent Note: 外壳铬件毛玻璃化

Status: implemented

## Problem

用户明确要求侧边操作栏与顶栏做毛玻璃高斯模糊，并要求从底层完整实现：不留兼容残迹、不做过渡妥协、不产生技术债。现行契约禁止毛玻璃与 `backdrop-filter`（DESIGN.md 视觉语言与可访问性性能两节），且外壳是「连续 L 形铬件框架 + 内嵌圆角工作区面板」布局：铬件占位、内容从不延伸到铬件之下，模糊无物可糊。用户指令构成设计契约变更，需要同时反转规则并重建外壳布局。

## Decision

铬件（`.asb-sidebar` 与 `.asb-titlebar`）是全应用唯二允许 `backdrop-filter` 的毛玻璃表面。材质由 tokens.css 一等拥有：`--asb-chrome-bg` 为模式自有半透明色（浅色 `hsl(240 12% 93% / 0.72)`，深色两个块各自定义 `rgb(17 30 43 / 0.72)`），`--asb-chrome-blur` 为模式无关的模糊材质；不派生、不复用旧 token。DESIGN.md 同批改写：毛玻璃与 backdrop-filter 仅对侧栏与顶栏解禁，其余内容面维持实体面禁令；页面结构段的事实改为满铺画布加悬浮铬件，删除 28px 圆角内嵌面板与 4px 露边的旧几何。

外壳布局重建为三层同构结构，DOM 顺序即绘制顺序：`.asb-shell`（relative 容器）下依次是 `.asb-sidebar`（左缘全高绝对定位玻璃）、`.asb-titlebar`（顶条绝对定位，left 跟随 `--asb-sidebar-width`）、`.asb-workspace`（`inset: 0` 满铺画布）。原 `.asb-body` 包装层删除——它只服务旧的流式框架布局；外壳不再保留 flex 布局、不可见底色或任何旧框架残迹。

`.asb-main` 是唯一的铬件预留契约：padding 上=标题栏高+16、左=侧栏宽+16，流式页面初始几何与旧框架逐像素一致；滚动时内容穿过 padding 区从玻璃下方经过被模糊。`scroll-padding-block-start` 保证键盘焦点与锚点滚动停在玻璃下方。侧栏收起时宽度变量同时驱动轨宽、标题栏 left 与 `.asb-main` 左边距，共用导航 400ms 与缓动。设置加载前的启动画面在壳外渲染，改用独立 `.asb-splash` 类，不占用铬件预留契约。更新徽标圆环改用铬件底色，与所在玻璃面一致。

带固定栏的受限滚动页（编辑器帧、扩展库、本地备份表）是页面解剖而非过渡：它们以 `:has()` 把 `.asb-main` 切到 `overflow: hidden`，固定头与固定底栏锚定在工作区内，滚动发生在页内受限区域，因此内容不从铬件下穿过。内容所有权不变：GlobalInformation、窗口控件、导航项、拖拽区归属维持原状；不新增持久化字段，不改变任何配置契约。

## Alternatives considered

- 系统级窗口材质（Tauri windowEffects acrylic/mica，托盘窗已有先例）：最强理由是能模糊桌面背景、得到真正的系统材质。放弃原因：主窗口按设计保持不透明，开启 transparent 会重漆整窗、干扰截图与深浅主题处理，且应用内滚动内容反而不参与模糊，与「内容穿过铬件」的预期相反。
- 受限滚动页 sticky 化（帧本身成为滚动容器、固定头与底栏 sticky，令编辑内容也从玻璃下穿过）：最强理由是让全部页面都有穿越效果。放弃原因：sticky 底栏在短内容页不再贴底，破坏 EditorFrame「固定底部操作栏恒在视口底」的既有契约；保持恒定贴底只能改为绝对定位叠层并测量头底高度，引入脆弱的高度耦合，比保留的解剖代价更高。
- 仅给旧框架的铬件换半透明底色：零布局风险，但铬件背后只有纯色底，模糊不可见，等于没做。

## Consequences

- 收益：外壳是三层各司其职的干净结构（玻璃轨、玻璃顶条、满铺画布），无包装层、无半截边框、无派生色；流式页面滚动内容在侧栏与顶栏下呈高斯模糊穿越；深浅主题、收起动画、拖拽区、键盘焦点滚动全部兼容。
- 代价：滚动时模糊区域持续重绘，接受这一开销并将旧「避免 backdrop-filter 重绘」条款收窄为铬件例外；不支持 backdrop-filter 的引擎退化为半透明底色（WebView2 与现代浏览器均支持，风险仅在理论）。纯纵向滚动的应用里，侧栏下方常态是画布底色，侧栏的玻璃感主要来自半透明叠色；穿越模糊的实际收益集中在顶栏。
- 不透明度与模糊半径是仅有的两个调节旋钮，集中在 tokens.css；业务组件不得自行引入 backdrop-filter 或毛玻璃底色。
- 验证限于笔记结构与静态检查；按项目规则未运行编译与自动化测试，模糊效果的实机视觉验收待用户运行确认。
